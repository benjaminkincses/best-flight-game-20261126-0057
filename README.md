Meridian Ridge is an original flight game over a mountain valley, drawn with a custom Canvas perspective renderer. Build speed on the runway, climb through eight glowing rings, then turn home and land gently for a fuel bonus. Use the arrow keys to bank and pitch, W/S to adjust throttle, P to pause, M to mute, and Enter to start or fly again. Watch airspeed, altitude and fuel: slow flight stalls and hard landings end the sortie.

## Run it

```sh
node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
